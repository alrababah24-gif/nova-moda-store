# Database Map

## `profiles`
يربط مستخدم Supabase Auth بدوره `customer` أو `admin`.

## `store_settings`
صف واحد `id=1` يحتوي إعدادات البراند، التوصيل، التواصل، Hero والشعار.

## `categories`
أقسام المتجر وترتيبها وحالتها.

## `products`
المنتجات، الأسعار، المقاسات، الألوان، الصور، المخزون، featured وactive.

## `orders`
بيانات العميل، الإجماليات وحالة الطلب.

## `order_items`
نسخة ثابتة من اسم المنتج والسعر وقت الطلب، حتى لو تغير المنتج لاحقاً.

## `testimonials`
آراء العملاء.

## `faqs`
الأسئلة الشائعة.

## `contact_messages`
رسائل نموذج التواصل وحالة القراءة.

## `page_content`
JSON مرن لمحتوى صفحات مثل `about`.

## Storage

- `product-images`: صور المنتجات.
- `brand-assets`: الشعارات والملفات البصرية القابلة للاستبدال.

## Order transaction

الدالة `create_store_order()` تعمل بـ `security definer` ولا يسمح بتنفيذها للزائر أو مستخدم authenticated العادي. API السيرفر يستدعيها بمفتاح service role. الدالة تقفل المنتجات المطلوبة، تتحقق من المخزون، تستخدم السعر من قاعدة البيانات، تحفظ الطلب والبنود، تخصم المخزون، ثم تعيد رقم الطلب والإجمالي.
